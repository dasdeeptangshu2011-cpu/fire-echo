# FIRE-ECHO 2.0

**Real hardware-connected environmental intelligence first. Interface second.**

FIRE-ECHO is a distributed wildfire early-warning/environmental-intelligence prototype built around ESP32 sentinels, an ESP32 verification robot, BLE communication, transparent sensor fusion, spatial estimation and an operator command center.

## Architecture

```text
ESP32 SENTINELS / ROBOT
        ↓
BLE COMMUNICATION
        ↓
NORMALIZED TELEMETRY
        ↓
BASELINES + SENSOR FUSION
        ↓
EVENT STATE
        ↓
WEIGHTED LOCALIZATION + UNCERTAINTY
        ↓
OPERATOR VERIFICATION
        ↓
ROBOT MISSION / TELEMETRY
        ↓
2D MAP + DIGITAL TWIN + ANALYTICS
```

## Data truth rule

Every displayed value has explicit provenance:

- **REAL** — received from a physically connected device.
- **CALCULATED** — computed from measurements/configuration.
- **ESTIMATED** — mathematically derived, such as event location.
- **SIMULATION** — generated by the safe simulation engine.
- **OFFLINE/REPLAY** — previously stored data.

A disconnected device is never represented as live hardware.

## Application

The command center contains Home, Live Map, 3D Digital Twin, Events, Incident Command, Robot Control, Sentinel Network, Hardware Center, Simulation Lab, Analytics, Research Mode, System Health, Calibration, Data History, Settings and About.

Simulation uses the same telemetry → fusion → localization → event pipeline as hardware, while keeping provenance explicit.

Use Simulation Lab / Competition Demo Mode. Do not use real fire or hazardous smoke. The demonstration progresses through environmental anomaly, corroboration, localization, operator dispatch and simulated robot verification.
